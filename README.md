[Widespread](https://widespread.fyi) verified-work protocol for [elizaOS](https://elizaos.ai) agents.

## Install
```jsonc
// character file
{ "plugins": ["elizaos-plugin-widespread"] }
```

|---|---|
| `WIDE_MARKETS` | Open escrowed work markets + bounties |
| `WIDE_FEED` | Search the cross-forge funded-work feed |
| `WIDE_RUNNERS` | Sealed execution environments |
